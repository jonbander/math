# مغامرة الأرقام والحساب للأطفال (عمر ٦ سنوات) 🌟
### Math Heroes - Educational Math Game for Kids

تطبيق ولعبة تعليمية تفاعلية ممتعة باللغة العربية مخصصة لأطفال عمر ست سنوات (الصف الأول والتمهيدي)، لتعليم:
1. ✏️ **كتابة ونطق الأعداد من ١ إلى ١٠** مع سبورة تتبّع تفاعلية تقارن الرسم بشكل الرقم الظاهر.
2. ➕ **الجمع البسيط حتى ١٠** عبر قصص مصورة وسلال فواكه ونجوم وأقلام.
3. ➖ **الطرح المرح** بشطب وأخذ العناصر لمعرفة الباقي.
4. ⚖️ **ميزان المقارنة التفاعلي** لمعرفة الأكبر (>) والأصغر (<) واليساوي (=) وقاعدة فم التمساح.
5. 🔬 **مختبر الحساب التفاعلي** وصانع المسائل الحسابية المخصصة.

---

## 📱 كيفية تحويل هذا المشروع إلى تطبيق أندرويد (APK)

المشروع مُهيأ لبناء تطبيق أندرويد APK عبر Capacitor وGitHub Actions. البناء التلقائي ينتج نسخة Debug للتجربة، أما نسخة النشر الموقعة فتحتاج إعداد مفتاح توقيع Android منفصل. يجمع سير العمل اختبارات الكتابة وفحص TypeScript والبناء قبل إنتاج APK.

يعتمد نطق العربية في Android على محرك تحويل النص إلى كلام المثبّت في الجهاز. إذا لم تتوفر بيانات صوت عربية، يعرض التطبيق تنبيهًا وزرًا لفتح إعداد تثبيت بيانات النطق. لا يحتوي المستودع على تسجيلات صوتية عربية مرفقة.

يحفظ التطبيق الأوسمة والمهام المكتملة محليًا على هاتف الطفل، ويعرض أحدث المهام في صفحة **حول التطبيق**. يمكن تصفير التقدم من الصفحة نفسها بعد تأكيد العملية؛ لا يُمسح إعداد الصوت، ولا تنتقل البيانات بين الأجهزة. حذف التطبيق أو مسح بياناته من إعدادات Android يحذف هذا التقدم المحلي.

### 🚀 الطريقة الأولى: البناء التلقائي عبر GitHub Actions (الأسهل دون تثبيت أي برامج!)
المستودع الحالي هو `jonbander/math` ويحتوي على `.github/workflows/build-apk.yml`.
1. ادخل إلى تبويب **Actions** في المستودع.
2. يعمل البناء تلقائياً عند رفع تغيير إلى `main` أو `master`، ويمكن تشغيله يدويًا عبر **Build Android APK > Run workflow**.
3. بعد اكتمال المهمة، نزّل `math-1.0.3-android-debug-apk` من قسم **Artifacts**.
4. انقل `app-debug.apk` إلى هاتف أندرويد وثبّته. هذه نسخة Debug وليست إصدار متجر موقّعًا.

تظهر صفحة **حول التطبيق** في القائمة، وتتضمن رقم النسخة **1.0.3** وتوقيع **أحمد** وخيار مسح التقدم المحلي.

### 💻 الطريقة الثانية: محلياً عبر Capacitor و Android Studio

1. **تثبيت Bun وبناء المشروع:**
   ```bash
   bun install --frozen-lockfile
   bun test
   bun run lint
   bun run build
   ```

2. **مزامنة منصة الأندرويد الموجودة في المستودع:**
   ```bash
   bunx cap sync android
   ```

3. **فتح المشروع في Android Studio:**
   ```bash
   bunx cap open android
   ```

4. **استخراج ملف الـ APK:**
   - من القائمة العلوية في Android Studio:
     `Build > Build Bundle(s) / APK(s) > Build APK(s)`
   - سيظهر لك إشعار يوضح مسار ملف الـ `app-debug.apk` الجاهز للتثبيت على الهواتف.

---

### 🌐 الطريقة الثالثة: عبر موقع PWABuilder (بنقرة واحدة مجاناً)

المشروع مزود بملف `manifest.json` وأيقونات PWA:
1. ارفع المشروع على أي استضافة ويب (مثل Vercel أو Netlify أو GitHub Pages).
2. افتح موقع: [https://www.pwabuilder.com](https://www.pwabuilder.com)
3. ضع رابط موقعك واضغط **Start**.
4. اضغط على **Android Package** ثم **Generate APK**.
5. ستحصل على ملف APK جاهز فوراً للتحميل والتثبيت على أي هاتف أندرويد.
